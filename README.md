# 秦彻 · 专属回忆

## 如何启动

双击 **启动.bat** 即可在浏览器中打开网页。

或者直接用浏览器打开 `index.html`。

---

## 📷 如何添加新照片

1. 把新照片复制到 `photos` 文件夹
2. 用记事本打开 `index.html`
3. 找到 `const photos = [` 这一行（大约在第 400 多行）
4. 在数组里添加你的新照片文件名，例如：

```js
const photos = [
  "你的新照片.jpg",   // ← 像这样添加
  "01d4419b001abcec35ce9724b1ab42ae.jpg",
  ...
];
```

5. 保存文件，刷新浏览器即可看到新照片

---

## 🎨 功能说明

- **西方龙剪影**：首页背景有浮动龙影动画
- **乌鸦元素**：分布在页面两侧
- **火焰粒子**：全屏飘浮的余烬粒子特效
- **照片墙**：点击可放大查看，支持键盘左右箭头切换
- **语录轮播**：每 5 秒自动切换，也可点击圆点手动切换
- **键盘快捷键**：照片放大后 ESC 关闭，← → 切换
- **音乐播放器**：底部迷你播放器，支持播放/暂停、上下切歌、列表循环/单曲循环、拖拽排序播放列表、点击进度条跳转

---

## 🎵 如何添加/更换音乐

1. 把 MP3 文件复制到 `music` 文件夹
2. 用记事本打开 `index.html`
3. 找到 `const musicFiles = [` 这一行（大约在 1000 行左右）
4. 在数组里添加或修改文件名即可
5. 支持拖拽排序播放列表（点击播放器右侧 ☰ 按钮打开列表）
